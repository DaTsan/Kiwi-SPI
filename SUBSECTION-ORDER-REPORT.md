# Сортировка подсекций — 11 октября 2026

Подсекции одного родителя можно переставлять мышью за значок ≡ слева в
заголовке. Верхняя половина заголовка соседней подсекции вставляет перед ней,
нижняя — после неё. При фокусе на значке доступны ↑/↓. Подсекция перемещается
целиком: вместе с вложенными уровнями, кейсами и состоянием сворачивания.

Порядок сохраняется в базе, используется в списке, дереве плана, RPC и при
сборе кейсов для новых прогонов. Новые подсекции добавляются в конец.
Миграция сохраняет прежний порядок существующих секций по ID.

Сортировка требует права редактирования родителя и всех его непосредственных
подсекций. При поиске она отключена. Сервер проверяет полный список соседей,
запрещает потерю/дублирование секций и перенос между родителями. Изменение
атомарно; устаревший список возвращает HTTP 409 и восстанавливается в браузере.
Изменения порядка фиксируются в истории с автором.
