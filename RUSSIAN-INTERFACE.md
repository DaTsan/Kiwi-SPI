# Русский интерфейс Kiwi-SPI

Дата проверки: 11 октября 2026 года. Ветка: `feature/testrail-workflow`.

## Как включить

Локальное приложение: http://127.0.0.1:8000/workflow/.
Русский установлен языком по умолчанию. Если браузер запомнил другой язык,
нажмите глобус → «Язык интерфейса» → «Русский» → «Применить».
Выбранный язык сохраняется в cookie и действует на обычных страницах,
в администрировании и в динамически загружаемых элементах.
Переключение обратно на English также поддерживается.

## Что переведено

- Меню, поиск, формы, сообщения об ошибках, стандартные статусы,
  страницы тест-кейсов, тест-планов, прогонов, дефектов и отчётов.
- Названия приложений, моделей и полей в администрировании.
- Добавленное планирование: этапы, циклы, общие шаги, пользовательские поля,
  пошаговое выполнение, история результатов, задачи и CSV-отчёты.
- Элементы JavaScript: таблицы и пагинация, подсказки календаря,
  списки выбора, панель Markdown-редактора, настройка расположения блоков.
- Русские формы множественного числа для количества шагов и секунд.

Обновлён серверный каталог `django.po`, добавлен каталог `djangojs.po`.
Для русского интерфейса поддерживаются коды `ru` и `ru-ru`.
В активных сообщениях обоих каталогов нет пустых или нечётких переводов.
Каталог JavaScript загружается до общего скрипта приложения, включая админку.
В локальном окружении отключён рекламный блок с внешним английским текстом.

Названия продуктов, текст кейсов, комментарии, пользовательские подписи полей
и другие введённые данные сохраняются в исходном виде. Ключи API и значения
статусов в базе не переименовываются; перевод применяется при отображении.
История результатов и снимки сценариев не переписываются.

## Проверки

Добавлены 14 тестов локализации: полнота каталогов, русские множественные формы,
компиляция шаблонов, JavaScript-каталог, 21 обычная и административная страница,
переключение языка, CSRF и безопасный возврат после переключения,
перевод CSV и сохранение пользовательских данных и истории.

Финальный расширенный прогон: `Ran 593 tests in 152.758s — OK (skipped=1)`.
Все 14 тестов локализации прошли. Единственный пропуск — существующая группа
`TestDashboardCheckMigrations`, которая включается отдельной переменной
`TEST_DASHBOARD_CHECK_UNAPPLIED_MIGRATIONS`.

Проверка Django: `System check identified no issues (0 silenced)`.
ESLint прошёл на всех девяти изменённых JavaScript-файлах.
Сборка Webpack, компиляция каталогов и сбор статических файлов завершились успешно.
Все новые миграции применены в локальной MariaDB.

В браузере проверены русские формы, административные разделы, поиск и таблицы,
а также переключение «Русский → English → Русский» с возвратом на ту же страницу.
Снимок: [русский интерфейс](artifacts/russian-interface.png).

Тесты запускаются в одноразовом контейнере с временной SQLite и не подключаются
к MariaDB локального приложения. Команда расширенного прогона:

```powershell
docker compose -f compose.test.yaml run --rm tests python manage.py test tcms.workflow.tests tcms.testcases.tests tcms.testplans.tests tcms.testruns.tests tcms.core.tests tcms.management.tests tcms.kiwi_auth.tests tcms.bugs.tests tcms.utils.tests.test_assign_permissions tcms.rpc.tests.test_testexecution tcms.rpc.tests.test_testcase tcms.rpc.tests.test_testrun --noinput --settings=local.test_settings
```

Сборка Docker компилирует каталоги, собирает JavaScript и статические ресурсы.
Миграции добавляют переводимые метаданные моделей и полей, без удаления моделей
или пользовательских записей. До обновления создана резервная копия локальной
базы в исключённой из Git папке `backups/`.

## Обновление переводов разработчиком

Для извлечения строк используется небольшой помощник `local/update_messages.py`.
Он вызывает штатный экстрактор Django напрямую: команда из текущей версии
зависимости vinaigrette несовместима с интерфейсом команд Django 6.
Имена стандартных статусов и подпись пустого выбора явно включены в извлечение.

```powershell
docker compose -f compose.test.yaml run --rm --user root tests python local/update_messages.py -l ru_RU
docker compose -f compose.test.yaml run --rm --user root tests python local/update_messages.py -l ru_RU -d djangojs
docker compose -f compose.test.yaml run --rm --user root tests python manage.py compilemessages -l ru_RU
```

После заполнения новых переводов пересоберите локальный образ через
`start-local.cmd`. Скомпилированные `.mo`, пароли, резервные копии и временные
журналы не включаются в Git.
